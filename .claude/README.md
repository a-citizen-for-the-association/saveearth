# .claude

このプロジェクト固有のClaude Code拡張を置くディレクトリです。

- `agents/` — プロジェクト固有のサブエージェント定義
- `commands/` — プロジェクト固有のスラッシュコマンド
- `settings.json` — プロジェクト共有設定（コミット対象）
- `settings.local.json` — 個人環境用の設定（`.gitignore`済み、コミット対象外）
