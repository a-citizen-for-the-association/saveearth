# docs

このプロジェクトのドキュメントを管理するディレクトリです。

- [design/](./design/) — 設計書（機能設計・システム設計など）
- [adr/](./adr/) — Architecture Decision Records（アーキテクチャ上の意思決定の記録）

## 使い分けの目安

| 用途 | 置き場所 |
|------|----------|
| 「何を」「どう作るか」を説明するドキュメント | `design/` |
| 「なぜその技術・方針を選んだか」という意思決定の記録 | `adr/` |

設計書は内容が更新されたら上書きしていくのに対し、ADRは決定した時点のスナップショットとして残し、後から変更する場合は新しいADRを追加して古いものを「Superseded」とします。
